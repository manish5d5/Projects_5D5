2. Smart-create behavior (tester rules)

POST /smart/exercise behaves as follows:

  1. Exercise exists: If exercise_name already exists → return existing exercise_id and do NOT insert.
  2. Muscle exists, exercise missing: Reuse muscle_id, insert only exercise.
  3. Workout exists, muscle missing: Reuse workout_id, insert muscle → exercise.
  4. Workout missing: Insert workout → muscle → exercise.

All steps must run inside a single transaction.
